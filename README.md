# NNDL-PJ1

本项目通过对神经网络在 MNIST 手写数字识别任务中的不断优化，从多个方面提升了模型的性能。从初始的多层感知机模型出发，通过调整网络结构、优化训练算法、应用正则化技术、改进损失函数、转换为卷积神经网络以及进行数据增强等一系列操作，逐步提高了模型的准确率和泛化能力。不同模型设置下的 Dev 准确率和 Test 准确率不同：在全连接层结构方面，增加隐藏层数量能一定程度提升准确率。优化器上，MomentGD 相较于 SGD 显著提升了准确率。损失函数加入正则化后，模型准确率进一步提高。引入卷积层可提升性能和泛化能力。综合来看，全连接层（[512,128]）搭配 MomentGD 优化器、交叉熵与正则化损失函数，或卷积层搭配同样的优化器和损失函数，能取得较高的准确率。最终模型在测试集上达到了 97% 的准确率，相较于初始模型有了显著提升。同时，通过对实验结果的分析，深入理解了各优化策略对神经网络性能的影响机制。例如，网络结构的调整需在模型表达能力和过拟合风险之间权衡；正则化方法能有效抑制过拟合；卷积神经网络在图像识别任务中具有独特优势等。然而，本项目仍存在一些局限。在模型计算效率方面，尽管 CNN 减少了参数数量，但在大规模数据和复杂任务下，计算量仍可能较大，计算时间相较MLP长得多，可进一步探索优化模型结构或采用更高效的计算框架。
